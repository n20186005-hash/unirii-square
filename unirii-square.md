# Unirii Square Travel Guide

Bilingual Next.js guide to Piața Unirii, Cluj-Napoca, Romania. Chinese uses / and English uses /en. The footer discloses the independent travel-information project.

Guides cover the square, Saint Michael’s Church, Bánffy Palace Art Museum and Museum Square with the Carolina Obelisk. Public sources and editorial dates accompany the content. Square access is separate from venue access.

Use the lockfile for installation. Existing scripts: npm run dev, npm run build, npm run start. Verify the established hosting runtime before changing deployment architecture.

All twelve original gallery files remain. No new third-party photographs are introduced.
